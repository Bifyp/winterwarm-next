# Production QA — Next.js migration

## Проверено локально

- `npm ci` и production-сборка из отдельной чистой копии: успешно, без готовых бинарных файлов и локальных кэшей. Asset manifest восстанавливает изображения/шрифты с проверкой SHA-256.
- Next.js production build: успешно, TypeScript strict включён.
- 12 unit/API-тестов: валидация, маршрутизация адресатов, Origin, тип/размер тела, honeypot, fail-closed, persistent rate limit, Turnstile hostname/action, ошибки почты/сети и idempotency.
- Playwright: **54/54 теста прошли**. 15 маршрутов на 1440/768/390 px, консольные ошибки и загрузка изображений; поиск, вкладки, mobile menu, brief fallback, legacy 308, настоящая 404, API без ключей, preview noindex и заголовки безопасности. Дополнительный regression test проверяет три видимые фотографии каталога.
- Полные снимки 16 маршрутов (включая 404) на desktop/mobile; состояния поиска, меню, пустого каталога и подготовленного brief. Просмотрены по отдельности. В каталоге восстановлены стабильные id XR+/gates/Skyline, от которых зависят исходные стили.
- `npm audit --omit=dev`: 0 обнаруженных уязвимостей на момент проверки. Это не гарантия отсутствия уязвимостей в будущем.
- Дизайн сохранён из предыдущего утверждённого направления: DM Serif Display + Hanken Grotesk, тёмно-синее поле, оранжевый акцент, реальные материалы компании. Новый draw/redraw не делался; это перенос стека, не редизайн. Линтер дизайн-навыка: 0 FAIL, 1 WARN про тире в исходных технических подписях. Предупреждение сохранено осознанно: подписи связывают оборудование с назначением.
- Нативный taste-inspector не завершил screenshot capture в этом окружении. Его успешный проход или новые эстетические баллы не заявляются. Проверка выполнена Playwright и индивидуальным просмотром PNG; геометрические измерения не заменяли визуальный просмотр.

- Реальная доставка писем Resend, ключи и лимиты внешних сервисов.
- Реальный Turnstile widget на production-домене и Redis credentials.
- DNS/HTTPS/redirect канонического домена.
- Юридическая политика, актуальность бизнес-данных и разрешения на материалы.
- Нагрузочный и внешний security audit, полноценный WCAG audit.

Никаких реальных заявок при локальных тестах не отправлялось. До настройки форма работает как честный e-mail brief, API закрыт с 503.
