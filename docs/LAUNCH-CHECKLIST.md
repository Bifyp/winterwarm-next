# Перед запуском

## Платформа
- [ ] Импортировать GitHub-репозиторий в свой Vercel project.
- [ ] Убедиться, что Vercel production build завершился успешно.
- [ ] Добавить домен и DNS по инструкции Vercel; проверить HTTPS и www/non-www.
- [ ] SITE_URL соответствует основному домену; старые .html редиректятся.
- [ ] Preview защищён средствами Vercel, если контент не должен быть публичным. `noindex` не является контролем доступа.

## Контент и права
- [ ] Владелец подтвердил тексты, контакты, цифры и параметры XR+/Skyline.
- [ ] Подтверждены права на фотографии/логотип и AI-сцену. AI-сцена подписана как концептуальная, не реальный объект.
- [ ] Юрист/владелец заполнил и утвердил полную privacy policy: юридическое лицо, основание, сроки хранения, права, трансграничные передачи и подрядчики Vercel/Resend/Cloudflare/Upstash.

## Форма
- [ ] Проверенный домен отправителя Resend, API key и получатели.
- [ ] Redis REST credentials и случайный RATE_LIMIT_SALT.
- [ ] Turnstile с разрешёнными hostname, public key при сборке, secret server-side.
- [ ] CONTACT_ENABLED=true только после всех предыдущих пунктов, затем Redeploy.
- [ ] Реальная заявка получена в нужной группе; Reply-To отвечает заявителю.
- [ ] Протестированы сбой почты, блокировка Turnstile, 429 и e-mail fallback.
- [ ] Включены уведомления об ошибках и мониторинг доставляемости в Resend/Vercel.

## SEO и приемка
- [ ] Проверены desktop/tablet/mobile и клавиатура на реальном deployment.
- [ ] SITE_INDEXABLE=true только на Production после одобрения; sitemap и canonical проверены на реальном домене.
- [ ] Настроены бюджет/лимиты Vercel, Upstash и Resend, ответственный за сопровождение.
