# Состояние демонстрационного сайта на Vercel

Публичный адрес: https://winterwarm-next.vercel.app

## Проверено и настроено

- Next.js 16, Node.js 24, Prisma schema validation, чистая установка зависимостей и production build.
- 21 unit/API/scaffold-тест и 61 браузерный тест Playwright: успешно.
- Браузерные проверки: 15 маршрутов на 1440/768/390 px, изображения, ошибки JavaScript, поиск, фильтры, клавиатурные вкладки, мобильное меню, подготовка brief, 404 и legacy redirects, API fail-closed, защитные заголовки и noindex.
- Отдельная проверка анимации заголовка на телефоне и планшете: не перекрывает описание.
- Проверены HTTP-ответы 18 production-маршрутов, включая robots, sitemap и несуществующий адрес: ожидаемые статусы.
- В Vercel настроен SITE_URL=https://winterwarm-next.vercel.app. SITE_INDEXABLE=false, CONTACT_ENABLED=false, SEED_DEMO_DATA=false.
- На production главная возвращает noindex/nofollow, корректный canonical и защитные заголовки.
- Перед публикацией этих правок Vercel Runtime Errors не показал ошибок за последние 24 часа. Это не нагрузочный тест и не гарантия отсутствия ошибок в будущем.
- Подпись демонстрации с авторами сохранена в общем хедере.
- Удалён текст об AI из hero и футера. Подпись источника относится к фотографиям продуктов и реализованных объектов, а не к концептуальной сцене главной.

## Границы готовности

Это работоспособная демонстрация, не полностью подключённый production-бэкенд.

- Каталог и поиск пока используют JSON, не PostgreSQL. Созданные в Supabase таблицы и 22 товара не означают интеграцию сайта с базой.
- DATABASE_URL зарегистрирован в окружении Vercel, но его значение не извлекалось и реальное Prisma-соединение из сайта не проверено. Значения sensitive-переменных скрыты API; пустое значение в таком ответе не доказывает, что пользователь оставил поле пустым.
- Запись заявок в PostgreSQL ещё не реализована. Автоматическая отправка формы выключена до согласования privacy policy и настройки реальных Resend/Turnstile/Redis credentials.
- Подготовка текста письма, mailto и скачивание brief доступны без сторонних ключей. Тесты не отправляли настоящих писем или клиентских заявок.
- Для дальнейшей интеграции БД см. SUPABASE.md, включая Prisma baseline для существующей схемы.
- Не выполнены нагрузочный/внешний security audit, полный WCAG audit, юридическая проверка материалов, настройка собственной почтовой инфраструктуры и проверка восстановления резервных копий.

Секреты не включены в GitHub и не публикуются в отчёте.

## Предупреждение при каждом входе и источники фотографий

- Перед просмотром любой HTML-страницы показывается полноэкранное предупреждение о демонстрации, авторах, неофициальном статусе, персональных данных и границах работы формы.
- Для продолжения требуется кнопка «Rozumiem — przejdź do demonstracji». Escape не скрывает предупреждение. Клавиатурный фокус остаётся внутри окна, затем переходит в основной контент.
- Подтверждение не сохраняется в cookies, localStorage или sessionStorage: предупреждение появляется при новом открытии/перезагрузке страницы, включая прямые ссылки и страницу 404. Для восстановления из browser back/forward cache предусмотрен обработчик pageshow.
- Предупреждение прокручивается на небольших экранах; начальный фокус стоит на заголовке, чтобы посетитель сначала видел начало текста, а не кнопку внизу.
- Поверх фотографий показываются ссылки на оригинальные файлы согласно docs/SOURCES.md и lib/photo-sources.ts. Меняющиеся фотографии в интерактивных разделах получают соответствующий источник.
